安装与验证

先把基础环境安装好
1. 安装 Node.js

直接访问 Node.js 官网 下载并安装最新 LTS 版本。

2. 安装 Codex 
npm install -g @openai/codex
3. 验证安装 
codex --version

配置文件位置

在当前用户目录中配置 `.codex`

进入当前用户目录下的 `.codex` 文件夹中。

Windows 常见路径示例：

C:\Users\你的用户名\.codex

如果没有 `.codex` 文件夹，请手动创建该文件夹。

然后在 `.codex` 文件夹中创建以下两个文件：

  • config.toml
  • auth.json

如果这两个文件已经存在，就直接修改即可，不需要重复创建。

auth.json 配置

先写鉴权令牌

将下面内容写入 auth.json：

{"OPENAI_API_KEY": "xxx"}
请将 xxx 替换成创建 API Key 时一次性返回的完整明文密钥，通常形如 sk-live-...。 不要填写密钥列表中展示的短前缀或掩码值；如果完整密钥已经丢失，请重新创建一个新的 Key。

config.toml 配置

直接粘贴下面内容即可 
model_provider = "zxw"
model = "gpt-5.4"
model_reasoning_effort = "high"
disable_response_storage = true
service_tier = "fast"

approval_policy = "on-request"
sandbox_mode = "workspace-write"

[model_providers.zxw]
name = "zxw"
base_url = "http://127.0.0.1:9988/v1"
wire_api = "responses"
requires_openai_auth = true

[mcp_servers]

[mcp_servers.memory]
type = "stdio"
command = "cmd"
args = ["/c", "npx", "-y", "@modelcontextprotocol/server-memory"]

[mcp_servers.sequential-thinking]
type = "stdio"
command = "cmd"
args = ["/c", "npx", "-y", "@modelcontextprotocol/server-sequential-thinking"]

[mcp_servers.time]
type = "stdio"
command = "cmd"
args = ["/c", "npx", "-y", "@modelcontextprotocol/server-time"]

[mcp_servers.context7]
type = "stdio"
command = "cmd"
args = ["/c", "npx", "-y", "@upstash/context7-mcp"]

[mcp_servers.fetch]
type = "stdio"
command = "uvx"
args = ["mcp-server-fetch"]

[sandbox_workspace_write]
network_access = false
writable_roots = [
]

[windows]
sandbox = "elevated"

参数说明

重点看这几个配置项
model_reasoning_effort

可选值为 high、medium、low，分别表示模型思考强度为高、中、低。

base_url

请记得根据自己的实际情况替换为正确的服务地址。

auth.json

这里的令牌要和你自己的实际使用令牌保持一致。

启动使用

配置完成后直接启动

配置完成后，重新打开终端，直接运行：

codex

如果配置没有问题，Codex 就可以正常启动并连接到你配置的模型服务。

常见问题

遇到报错先检查这里
  • 如果终端提示找不到 codex，请重新执行 npm install -g @openai/codex。
  • 如果 codex --version 没有输出版本号，请先检查 node -v 和 npm -v 是否正常。
  • 如果没有 .codex 文件夹，可以手动创建，不影响使用。
  • 只要 .codex 目录下最终包含 config.toml 和 auth.json 即可。
