# 2026-05-08 前端修改汇总

## 本次确认有调整的页面

- `src/app/pages/PackageCenter.tsx`
- `src/app/pages/Channels.tsx`

## 套餐中心 `PackageCenter.tsx`

### 1. 修复页面乱码和编译异常

- 清理了页面标题、表格表头、按钮文案、弹窗标题、提示文案里的乱码字符。
- 修复了损坏的 JSX 文本节点，避免页面因为字符串断裂导致编译失败。
- 统一了空值显示，时间为空时显示 `—`。

### 2. 套餐表单改为“按需填写”

- 新增套餐时，`套餐价格 / 有效天数 / 日额度 / 周额度 / 月额度` 改为可选。
- 这些输入框的占位文案改成了“可选，留空即可”。
- 默认表单里去掉了之前的默认数值，避免一打开就自动带价格和额度。

### 3. 余额套餐文案和交互调整

- 余额套餐不再提示“默认售价为 0”，改成“不需要填写价格和额度”。
- 余额套餐说明改成按余额实时扣费的描述，和当前业务更一致。

### 4. 套餐列表展示优化

- 修正了套餐中心首页的统计卡片文案：
  - 套餐总数
  - 系统预置
  - 当前生效
  - 关联模型数
- 修正了表格列名：
  - 套餐
  - 类型
  - 价格 / 周期
  - 额度配置
  - 模型 / 状态
  - 到期 / 备注
  - 操作
- 普通套餐额度显示改成：
  - 日额度
  - 周额度
  - 月额度
- 停用按钮、修改弹窗、备注字段等相关中文文案一并修正。

## 渠道 / 模型商店 `Channels.tsx`

### 1. 删除“拉取并导入上游模型”里的默认价格输入

- 导入上游模型时，不再保留默认的价格字段和倍率字段输入。
- 当前导入弹窗只保留：
  - 渠道
  - 导入到套餐组
  - 是否公开
  - 上游模型勾选导入

### 2. 清理模型商店页面乱码

- 修复了渠道列表、模型商店、弹窗、表格、状态标签中的乱码文案。
- 修复了状态文案和按钮文案：
  - 运行中
  - 已停用
  - 启用
  - 停用
  - 添加渠道
  - 添加模型
  - 拉取并导入上游模型

### 3. 模型和渠道弹窗中文文案修正

- 新增渠道弹窗字段文案改为正常中文。
- 新增模型 / 修改模型弹窗字段文案改为正常中文。
- 导入上游模型弹窗中的按钮、提示和空状态说明改为正常中文。

### 4. 导入逻辑保持“按上游模型原值导入”

- 前端导入请求现在只传：
  - `providerId`
  - `groupId`
  - `upstreamModels`
  - `isPublic`
- 前端不会在导入时额外拼默认价格，也不会自动改模型名。
